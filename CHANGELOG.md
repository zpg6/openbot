# Changelog

OpenBot records user-visible and operator-visible changes here. The project follows Keep a Changelog and uses semantic versioning once releases begin.

## Unreleased

### Added

- Added an unwired exact-predecessor lease takeover. It requires the reviewed generation and record digest before and after process-liveness adjudication, performs at most one checkout-local lease mutation, then revalidates the complete recovery view. Its receipt authorizes no dispatch, cleanup, replay, state transition, lifecycle, or gate action.
- Added an unwired read-only recovery state-transition candidate. It double-checks the recovery session and active lease, then returns `not_compiled` until a keyed response-semantic projector can derive the next operation identity from the archived response. It performs no state write and grants no transition authority.
- Added an unwired secure launcher for the fixed disabled canary child. It passes copied secrets only through descriptors 3 and 4, clears the child environment, enforces command, output, deadline, and termination bounds, accepts one strict canonical child result, clears captured buffers, and grants no evidence or downstream authority. Production callers cannot inject a process implementation. Failure to prove child exit rejects outside the canonical result union and requires a fatal process-tree supervisor before wiring.
- Extended every scalable local E2E operation through durable restart observation and cleanup-resumption planning. Reviewed benchmark reports now require one successful recovery session and one safe cleanup plan per operation in addition to durable transcript reconstruction and contention proofs. The harness removes only validated synthetic records left by an interrupted run and waits for each bounded batch to finish cleanup before starting the next batch.
- Added an unwired observation-only durable-driver restart session that double-samples and joins the exact operation, active lease record, recovery classification, durable transcript, journal head, and archive count. It returns fixed no-retry dispositions without acquiring or taking over a lease, repairing an archive, changing state, exposing raw execution identity, or granting authority.
- Added a read-only cleanup-resumption planner that verifies stable consistency, recovery, and cleanup-obligation records. It distinguishes cleanup entry, the crash window after entering cleanup but before its first request, cleanup continuation, local transition revalidation, ambiguous read-only reconciliation, and completed absence. It sends no request and grants no cleanup or replay authority.
- Added durable-session identity contention to the scalable local E2E and a `bench:base-layer:reviewed` runner. The fixed runner validates the maximum-scale and maximum-payload reports, including concurrency, record counts, five identity-substitution classes, zero contention writes, and false authority.
- Added an unwired private durable Worker-canary driver session that owns bootstrap lease identity and creates joined response-claim hooks only for the exact immutable execution identity. The scalable local E2E now uses that session instead of manually joining the lease owner to the response-claim factory. The session prepares or dispatches no request, exposes no raw lease or execution identity, and grants no dispatch, cleanup, lifecycle, or gate authority; the credentialed runner still does not use it.
- Added an unwired crash-aware Worker canary driver bootstrap that establishes or reuses the exact prepared operation state and cleanup obligation, rejects prior effect or archive history, acquires the cooperative lease, and reasserts all local heads before returning a non-authoritative session. Cleanup-obligation reads are now plan-scoped under unrelated concurrent publication. The scalable local E2E exercises this boundary and reports completed bootstraps; the credentialed runner does not.
- Added a read-only durable Worker canary transcript that reconstructs redacted request history from stable effect and encrypted-archive records after restart. The scalable local E2E workload compares that reconstruction with the live transport transcript for every operation. It exposes no raw path or body and grants no replay, cleanup, lifecycle, or gate authority.
- Added a configurable local base-layer E2E benchmark over the public operation, lease, effect, cleanup-obligation, response-archive, and recovery APIs. It records correctness counts, throughput, latency percentiles, and same-plan revision-zero CAS contention without credentials or remote requests. Archive inventory snapshots are now plan-scoped, so unrelated concurrent operations do not cause false instability.
- Made base-layer completion the explicit prerequisite for product-facing work: durable identities, append-only state, effect, and archive histories, lease epochs, composed dispatch-response sessions, tri-store consistency, recovery reducers, cleanup obligations, and authority separation.
- Pure offline helpers generate canonical Cloudflare Worker API canary plans and check a returned transcript's caller-claim shape against retained operator context. They perform no network or filesystem work, do not resolve response digests, and grant no mutation, adjudication, lifecycle, or gate authority.
- Added a non-mutating Worker API canary plan CLI, a strict response projection, a checkout-local canonical operation store with a durable delete-dispatch fence, and an unwired automatic-cleanup core. The credentialed runner does not use them yet, and no live run, cleanup CLI, secure launcher, manual authority, or observation promotion is enabled.
- Added a read-only Worker API canary recovery inspector that reports only redacted local journal status. The canary now uses one bounded transport and transcript for forward and cleanup requests. The credentialed implementation remains in source for testing, but its root and package commands are unregistered and its former executable module is a fixed denial.
- Added unwired checkout-local primitives for a cooperative single-process driver lease and a caller-constructible redacted effect-claim hash chain. Neither primitive authenticates Cloudflare effects, grants mutation authority, or is consumed by the credentialed runner.
- Unified the canary execution-nonce commitment across operation, lease, and effect records. Every effect claim now binds its exact lease generation and canonical lease-record digest. The unwired read-only checker double-samples all three histories and rejects historical lease drift, unresolved residue, unstable heads, impossible ordering, and multi-step gaps. Its redacted snapshot may become stale and cannot authorize work.
- Added a one-use caller-controlled pre-dispatch ordering hook and an encrypted response-body archive for the Worker canary. The current runner persists no claims through the hook and writes no archive records. Neither addition authenticates Cloudflare effects or grants mutation authority.
- Added an unwired forward-only adapter that records timed dispatch intent and start claims under exact lease and journal-head checks, plus a bounded caller-controlled response-byte hook. The adapter writes no terminal claim or cleanup claim, the hook cannot prove archive publication and cannot prevent callers from retaining plaintext, and the credentialed runner uses neither primitive.
- Added an unwired joined forward response-claim adapter and a read-only redacted archive inventory. The adapter archives response bytes before appending its terminal claim, but direct public journal append remains caller-constructible. The inventory authenticates no envelope, response, key possession, decryptability, or claim persistence. The runner uses neither addition, and end-to-end capture remains false.
- Added an unwired read-only base recovery classifier over stable operation, effect, lease, and encrypted-archive shape snapshots. It distinguishes aligned, intent-only, ambiguous no-retry, missing-archive, and archive-ahead states, but performs no decryption, mutation, state transition, cleanup, or authority decision.
- Added an unwired keyed archive-ahead reducer. It verifies one encrypted response against the exact started claim, current lease epoch, unchanged local heads, AES-GCM tag, and plaintext digest, then appends only the missing `response_observed` claim. It exports no plaintext, sends no request, transitions no operation state, and grants no cleanup, lifecycle, attestation, or gate authority.
- Extracted the Worker canary cleanup grace into a pure shared contract and added an unwired immutable private cleanup-obligation record that binds it to the prepared operation and execution commitment before remote work. Read-only verification performs no write; the caller-constructible record authenticates no effect, grants no cleanup authority, and is not consumed by the credentialed runner.
- Bound the cleanup-obligation digest across cleanup dispatch and response claims, encrypted archive AAD and receipts, redacted inventory, consistency snapshots, base recovery, and archive-ahead reconciliation. Forward claims require a null digest. Cleanup adapters reassert the immutable record and its separate grace window, while the disabled credentialed runner remains unwired and every record remains non-authenticating and non-authoritative.
